# Projeto Integrador

Esta pasta reúne projetos desenvolvidos durante minha trajetória acadêmica no **Instituto Federal Catarinense (IFC) — Campus Araquari**, como parte das atividades práticas de formação na área de tecnologia e desenvolvimento de software.

Os arquivos representam experiências de aprendizagem, aplicação de conhecimentos teóricos e desenvolvimento de soluções utilizando tecnologias e ferramentas de programação.

O conteúdo desta pasta documenta parte da minha evolução técnica e acadêmica, reunindo trabalhos que contribuíram para o aprimoramento de habilidades em desenvolvimento web, estruturação de aplicações e criação de interfaces.

**Objetivo:** organizar e preservar os projetos desenvolvidos durante o período acadêmico, mantendo um registro das experiências e dos conhecimentos adquiridos ao longo da formação.
