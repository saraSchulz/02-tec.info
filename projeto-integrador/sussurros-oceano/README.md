# Sussurros do Oceano

## Sobre o projeto

O **Sussurros do Oceano** é um projeto de desenvolvimento web voltado à conscientização ambiental e à preservação dos ecossistemas marinhos, abordando temas relacionados à fauna marinha, à poluição dos oceanos e às formas de contribuição para a conservação ambiental.

A aplicação foi organizada em páginas e componentes reutilizáveis, permitindo apresentar informações de maneira estruturada e facilitar a navegação entre os diferentes conteúdos.

## Conteúdo da aplicação

- **Página inicial:** apresentação do projeto e informações introdutórias.
- **Fauna marinha:** conteúdos relacionados à vida marinha e à importância de sua preservação.
- **Poluição:** informações sobre a poluição marinha e seus impactos ambientais.
- **Contribuição:** conteúdos relacionados a iniciativas e formas de contribuir para a preservação dos oceanos.
- **Sobre nós:** apresentação da equipe e dos objetivos do projeto.

## Tecnologias utilizadas

## Como executar

É necessário ter o Node.js e o npm instalados.

1. Acesse a pasta raiz do projeto.
2. Instale as dependências:

   ```bash
   npm install
   ```

3. Inicie o servidor de desenvolvimento:

   ```bash
   npm run dev
   ```

4. Acesse no navegador o endereço local apresentado pelo Vite.

## Objetivo acadêmico

O projeto reúne conhecimentos de desenvolvimento front-end, organização de aplicações com Vue.js, criação de componentes reutilizáveis e navegação entre páginas.

Além do aspecto técnico, busca utilizar a tecnologia como ferramenta de informação e conscientização sobre a preservação ambiental, aproximando o desenvolvimento de software de questões relevantes para a sociedade.
