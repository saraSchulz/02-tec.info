# Projetos Vue.js — IFC Araquari

Esta pasta reúne sete projetos desenvolvidos durante minha trajetória acadêmica no Instituto Federal Catarinense (IFC) — Campus Araquari. Os exercícios registram a evolução prática no desenvolvimento de interfaces web com **Vue.js**, utilizando conceitos de reatividade, componentes, propriedades computadas, manipulação de listas e navegação entre páginas.

## Projetos incluídos

1. **Vue-01_contador** — contador interativo com limites mínimo e máximo e incremento configurável.
2. **Vue-02_listaTarefas** — lista de tarefas com inclusão, edição, exclusão e ordenação.
3. **Vue-03_ListaCompras** — gerenciamento de itens com identificadores, status, pesquisa e contagem de tarefas.
4. **Vue-04_PropriedadesComputadas** — demonstração de `ref`, `computed`, vinculação de campos e comparação com funções.
5. **Vue-05_components** — evolução da lista de tarefas com componentes reutilizáveis e comunicação entre componentes.
6. **Vue-06_ListaCatalogo** — catálogo de produtos organizado por categorias, com componentes e rotas.
7. **Vue-07_Livraria** — interface de livraria com catálogo de livros, páginas de detalhes, equipe e componentes de carrinho.

## Tecnologias e ferramentas

- Vue.js 3
- JavaScript
- Vite
- Vue Router nos projetos que utilizam navegação
- HTML e CSS
- npm para gerenciamento de dependências

## Como executar um projeto

Cada subpasta é um projeto independente. Para executar um deles localmente, tenha uma versão compatível do Node.js e o npm instalados e siga os passos:

```bash
cd Vue-01_contador
npm install
npm run dev
```

Substitua `Vue-01_contador` pelo nome da pasta que deseja executar. O terminal informará o endereço local para abrir no navegador.

## Objetivo

Este conjunto funciona como registro de aprendizagem e prática, reunindo exercícios que demonstram a aplicação gradual de conceitos fundamentais do desenvolvimento front-end. Os projetos podem ter diferentes níveis de complexidade e representam etapas de estudo, não necessariamente aplicações finalizadas para produção.
